## Descrição da Disciplina

A unidade curricular aborda os conceitos e padrões fundamentais para a criação de aplicações web modernas, focando na linguagem JavaScript e nas técnicas essenciais de desenvolvimento Frontend.

---

## Objetivos

* Compreender a sintaxe moderna e o fluxo assíncrono do JavaScript (ES6+).
* Dominar a manipulação da árvore DOM e o tratamento de eventos no navegador.
* Desenvolver páginas interativas com consumo de dados de APIs externas.
* Construir interfaces web dinâmicas, estruturadas e com código legível.
